Site Plan: corbinpro

Corbin Probasco | WDD131

Purpose

Portfolio site to show my embedded systems and software projects to hiring managers and recruiters. Video demos, downloadable resume, and a contact form.

Audience

Hiring managers in embedded systems, defense, and manufacturing. Fellow students and collaborators. BYU-Idaho faculty.

Dynamic Elements

  • Project tag filter - array of objects, forEach, filter, DOM rendering, URL param support
  • Contact form validation - validateField(), handleSubmit(), input/blur/submit listeners, error messages
  • Typing animation - array of role strings, setTimeout, type/delete cycle
  • Dark mode toggle - data-theme attribute, CSS variable overrides, localStorage
  • Hero parallax - scroll-driven blur, zoom, and fade using scroll event listener
  • Image carousels - stacked card shuffle, exploded hover view, fullscreen lightbox

Logo

"CP" with terminal cursor. Green on black. 48x48 in nav.
