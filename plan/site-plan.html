Purpose

This portfolio website serves as a professional showcase for Corbin Probasco, a Software Engineering student and Junior Developer specializing in embedded systems and computer vision. The site presents completed projects through video demonstrations, provides a downloadable resume, and offers a way for recruiters, hiring managers, and collaborators to make contact. The goal is to demonstrate technical competence through tangible project outcomes rather than just listing skills.

Target Audience

The primary audience includes software engineering hiring managers, recruiters in the embedded systems and defense technology sectors, and fellow engineering students or open-source collaborators. These visitors are technically literate, value concise presentation, and want to quickly assess project scope and quality. A secondary audience includes BYU-Idaho faculty evaluating coursework. The site's minimal design and monospace typography signal engineering credibility, while video demonstrations let non-technical stakeholders quickly grasp project outcomes.

User Scenarios

  1. "I'm a recruiter reviewing candidates for an embedded systems role. I want to quickly see what projects this candidate has built and whether they can demonstrate working hardware/software integration."
  2. "I'm a fellow student looking for collaboration on a drone-related project. I want to see what tools and platforms Corbin has experience with and find a way to reach out."
  3. "I'm a hiring manager at a defense contractor. I saw Corbin's LinkedIn and want to see video evidence of his computer vision turret and RF signal detector projects before scheduling an interview."

4. Dark Mode Toggle (All pages)

Toggle button in the nav bar swaps CSS custom properties between light and dark theme objects.

  • Two theme objects (light and dark) with CSS variable key-value pairs
  • Object.entries(theme).forEach() to apply properties to document.documentElement
  • Stores preference in localStorage, reads on page load
  • Conditional: check if saved preference exists, apply accordingly

Implementation:

const themes = {
  light: {
    '--bg-primary': '#FFFFFF',
    '--bg-secondary': '#F8F8F8',
    '--text-primary': '#2C2C2C',
    '--text-secondary': '#6B7280',
    '--accent-primary': '#C9A835',
    '--accent-secondary': '#CC6666',
    '--bg-dark': '#1E1E1E',
    '--border': '#E5E7EB'
  },
  dark: {
    '--bg-primary': '#1A1A14',
    '--bg-secondary': '#252520',
    '--text-primary': '#D4CFC4',
    '--text-secondary': '#8A8575',
    '--accent-primary': '#C9A835',
    '--accent-secondary': '#CC6666',
    '--bg-dark': '#0F0F0A',
    '--border': '#3A3A30'
  }
};

function applyTheme(themeName) {
  const theme = themes[themeName];
  Object.entries(theme).forEach(([prop, value]) => {
    document.documentElement.style.setProperty(prop, value);
  });
  localStorage.setItem('theme', themeName);
}

const saved = localStorage.getItem('theme');
applyTheme(saved ? saved : 'light');

Covers: objects, arrays, Object.entries, forEach, DOM interaction, event listener, conditionals

/* === TABLET+ (min-width: 768px) === */
